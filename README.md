# OneConnect: An AI multi-agent

## Description: 
An AI Multi-Agent that will use to perform following task:
- Book a train ticket or a movie ticket
- Buy products just give product description as prompt[Amazon,Flipkart,Ajio,Myntra]
- Order food from Zomato, Swiggy or book a table in a restaurant
- Order groceries on Blinkit, Zepto
- Schedule tasks and events
- And More

## Tech Stack
- Langchain/Langgraph Agentic Framework
- Groq Api for LLM Calls
- MCP for Host, Client and Server Environment
- Arize Phoenix for Agent Evaluation
